# 智教 Harness

面向教师的工作台。只看界面时不必启动后端。

## 单独启动前端

需要 Node.js `^18`、`^20` 或 `>=22`。在仓库根目录执行：

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。Vite 固定使用这个端口；5173 已被占用时启动会失败。依赖已装过时，下次只运行 `npm run dev`。

这条命令不启动 Python API。页面里的 `/api` 会代理到 `http://127.0.0.1:8000`。本机 8000 没有服务时，工作台仍能打开，并进入界面预览：

- 侧栏显示「本机服务未连接，当前只预览界面。」
- 左下角账号显示「界面预览」
- 可以直接输入并发送。回复是本地文字：「本机服务还没接上。这是界面预览，正式回复会出现在这里。」
- 句子里含「点名」「计时」或「投票」时，预览会多给出一条待审批的工具调用
- 预览会话只留在当前页面，刷新后清空
- 预览里的「退出登录」和「切换账号」不会进入登录表单

后端稍后启动后，刷新页面会回到真实登录，不再使用这份预览。
