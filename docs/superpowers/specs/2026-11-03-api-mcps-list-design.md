# API/MCPs 配置列表界面

日期：2026-11-03  
状态：已确认方向，待实现

## 1. 目标

把设置里的「API/MCPs配置」从整页表单，改成参考「模型提供商列表」的摘要列表：默认只看名称与联通状态，详细字段收进「编辑」后的行内展开区。

不引入多提供商后端，不改变现有 `/api/llm/config` 与 `/api/llm/probe` 契约。

## 2. 范围

### 做

- 列表两行：`本机环境`、`自行填写`（英文界面用现有文案键）。
- 每行：名称、状态点 + 短状态文案、右侧「编辑」。
- 点「编辑」行内展开现有字段：服务地址、模型、密钥、联通状态；再点可收起。
- 展开「本机环境」时字段只读；展开「自行填写」时可改，探测逻辑与现在一致。
- 底部虚线按钮「+ 添加模型提供商」；点击后轻提示「尚未开放」（或对应英文）。
- 保留底部 MCP 尚未接入的说明。
- 更新相关前端测试与中英文文案。

### 不做

- 真实多提供商增删与持久化。
- 改后端 API、环境变量语义或密钥展示方式。
- 改侧栏其它设置项或整站导航结构。

## 3. 界面与交互

### 3.1 默认视图

```
API/MCPs配置
短导语（填密钥/选来源即可使用）

┌ 本机环境          ● 已联通          [编辑] ┐
└──────────────────────────────────────────┘
┌ 自行填写          ● 未配置          [编辑] ┐
└──────────────────────────────────────────┘

+ 添加模型提供商（虚线边框）

MCP 说明
```

### 3.2 状态映射

沿用现有 `probe` 结果，按当前展开或该行对应来源分别探测：

| 内部状态 | 点颜色 | 列表短文案 |
| --- | --- | --- |
| `up` | 绿 | 已联通 |
| `down` / `offline` | 红 | 连不上… / 暂时连不上本机服务 |
| `unset` | 灰 | 未配置 |
| `checking` | 灰/弱动画 | 正在检测 |
| `idle` / 其它 | 灰 | 未检测 |

列表行在未展开时也显示该来源最近一次探测结果；首次进入应对两行分别探测或复用现有加载后的探测。

### 3.3 编辑展开

- 同一时间只展开一行。点另一行的「编辑」时，收起当前行再展开新行。
- 展开区内不再出现「本机环境 / 自行填写」分段开关；来源由所在行决定。
- 「编辑」在展开时可改成「收起」，或保持「编辑」再次点击收起；实现选一种并在测试中固定。
- 自行填写的输入与 400ms 防抖探测行为保持与现实现一致。

### 3.4 添加按钮

- 文案：`+ 添加模型提供商`（英文：`+ Add model provider`）。
- 行为：调用与加号菜单相同的「尚未开放」toast，不打开表单。

## 4. 数据与实现边界

- 数据仍来自 `loadLlmSources` + `probeLlm`。
- 主要改动文件：`frontend/src/components/Settings.tsx`、`frontend/src/styles.css`、`frontend/src/lib/appearance.tsx`（文案）、`frontend/src/pages/Workbench.test.tsx`（若有设置相关断言）。
- 不新增存储、不写 `.env`。

## 5. 验收

1. 进入「API/MCPs配置」先看到两行摘要，不直接看到整页输入框。
2. 点「本机环境」编辑：展开只读字段与联通状态；字段与环境变量一致。
3. 点「自行填写」编辑：可改地址/模型/密钥，联通状态随探测更新。
4. 同时只展开一行。
5. 「添加模型提供商」出现尚未开放提示。
6. 现有 API 配置探测相关测试更新并通过；中英文切换下列表与按钮文案正确。

## 6. 风险

- 两行都要状态时，探测次数可能变多；用已有防抖/取消逻辑避免竞态。
- 列表短文案若过长，用单行省略，完整句保留在展开区或 `title`。
