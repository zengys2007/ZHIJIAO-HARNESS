# API/MCPs 提供商「编辑」展开面板

日期：2026-11-03  
状态：已确认方向，待实现

## 1. 目标

把设置里提供商列表点「编辑」后的行内区域，改成接近参考图的结构：密钥、可折叠自定义设置（API 地址）、单行模型目录、取消/保存。只改版式与交互壳，不引入多模型持久化或写 `.env`。

## 2. 范围

### 做

- 摘要行保持：名称、状态点 + 短文案、「编辑」/「收起」（或展开后仍用编辑按钮配合底部取消）。
- 展开区结构（自上而下）：
  1. 标题行：提供商显示名 + 来源标识（`local` / `dotenv`）。
  2. **API 密钥** 输入；无密钥时橙色提示。
  3. **自定义设置**（默认可展开）：内含 **API 地址** 与简短说明。
  4. **模型目录**：展示当前配置的那一个模型（一行）；「+ 添加模型」→ toast「尚未开放」。
  5. 右下 **取消** / **保存**。
- 「本机环境」字段全部 disabled；「自行填写」可改密钥/地址/模型，现有 400ms 防抖 `probe` 保留。
- 展开区内不再单独放「联通」整行；状态继续看摘要行状态点。
- 更新中英文文案、样式与相关前端测试。

### 不做

- 不写 `.env`、不改 `/api/llm/config` / `/api/llm/probe`。
- 不做真实多模型增删、模型别名映射持久化。
- 不改侧栏其它设置项；不加参考图里的账号余额顶栏（除非已有）。

## 3. 交互细则

| 控件 | 行为 |
| --- | --- |
| 取消 | 自行填写：还原为打开编辑时的草稿；然后收起。本机：直接收起。 |
| 保存 | toast「尚未开放」，然后收起；内存中的自行填写草稿可保留（与当前探测一致）。 |
| + 添加模型 | toast「尚未开放」。 |
| 模型行删除/展开图标 | 可选展示以贴近参考图；点击同样「尚未开放」。 |
| 自定义设置折叠 | 可折叠；默认展开。 |

橙色密钥提示：自行填写且后端 `has_api_key` 为假且输入为空时显示；本机无密钥时用只读提示语气。文案键新增，中英齐全。

## 4. 数据与文件

- 数据仍来自 `loadLlmSources` + `probeLlm`。
- 主要改动：`frontend/src/components/Settings.tsx`（`ApiConfig` / `renderEditor`）、`styles.css`、`appearance.tsx`、`Workbench.test.tsx`。

## 5. 验收

- 点「编辑」看到密钥、自定义设置（含地址）、模型目录、取消/保存。
- 本机环境输入 disabled；自行填写可改且仍会探测。
- 添加模型 / 保存 → 「尚未开放」；取消收起且自行填写草稿还原。
- 列表摘要状态点仍可用。
