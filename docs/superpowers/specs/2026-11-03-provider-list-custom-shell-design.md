# API/MCPs：去掉自行填写 + 本地自定义提供商壳

日期：2026-11-03  
状态：已确认方向，待实现

## 1. 目标

设置「API/MCPs」列表去掉「自行填写」；支持「+ 添加模型提供商」后出现可编辑/删除的自定义行（参考图样式）。自定义数据只存浏览器 localStorage，不接后端多提供商。会话模型浮层本阶段仍只列本机环境。

## 2. 范围

### 做

- 移除列表中的「自行填写」行及设置页对 `dotenv` 的编辑/探测 UI。
- 固定一行「本机环境」：状态点 +「编辑」，无「删除」。
- 「+ 添加模型提供商」打开简易对话框：必填名称；可选 API 地址、模型、密钥；确认后追加列表行。
- 自定义行：状态点（有地址+模型+密钥则可探测或显示「未检测/未配置」简化态）、「编辑」「删除」（直接删除，无二次确认）。
- 自定义行持久化：`localStorage` 键带版本前缀（如 `zhijiao.providers:v1`）。
- 本机「编辑」：沿用现有展开面板，字段只读；取消收起；保存仍 toast「尚未开放」后收起。
- 自定义「编辑」：同一面板；可改名称与字段；取消还原打开时草稿；**保存写回 localStorage 并收起**。
- 导语文案贴近「填入各提供商的 API 密钥即可使用其模型」。
- 不展示参考图顶部的「账号已登录」条。
- 更新前端测试与中英文案。

### 不做

- 不写 `.env`、不改后端多提供商 API。
- 模型浮层不列自定义提供商；发消息选源逻辑仍只认 `local`（及既有 `dotenv` API 若别处仍用，设置 UI 不再引导）。
- 不做真实账号登录态行。

```
└──────────────────────────────────┘
┌ amazon-bedrock  ● …   [编辑][删除] ┐  ← localStorage
└──────────────────────────────────┘

+ 添加模型提供商
```

## 4. 数据形状（前端）

```ts
type CustomProvider = {
  id: string; // uuid/hex
  name: string;
  base_url: string;
  model: string;
  api_key: string; // 仅存本机；勿上传、勿打日志
};
```

状态点：本机继续用现有 probe；自定义行可用简化规则——三项齐全显示「未检测」或可选本地 probe（非必须）；缺项「未配置」。

## 5. 与模型浮层

- `ModelPicker` 继续只展示 `/api/llm/config` 中已配齐的 `environment`（及若仍返回的 dotenv 可不在 UI 强调）。
- 不因自定义提供商改变 `llm_source` 契约。

## 6. 验收

- 设置页无「自行填写」。
- 可添加、编辑保存、删除自定义行；刷新后仍在。
- 本机不可删除；编辑面板只读。
- 添加提供商对话框校验：名称为空不可提交。
- 相关 Vitest 更新并通过。
